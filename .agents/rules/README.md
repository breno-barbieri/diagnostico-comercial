# `.agents/rules/`

Regras obrigatórias por assunto. Um assunto por arquivo, curto.

| Arquivo            | Carregar quando                                                                 |
| ------------------ | ------------------------------------------------------------------------------- |
| `writing-voice.md` | Qualquer texto que uma pessoa vai ler: chat, doc, commit, texto da página, prompt de IA. |

Para criar regra nova: confirme que não cabe em arquivo existente, escreva `<assunto>.md`, registre aqui e no roteador do AGENTS.md.
